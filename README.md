## 作品について

宮中での『日本書紀』講読（日本紀講筵）の終わりに開かれた竟宴で、神々や天皇を題に分け与えられて詠んだ歌の記録。元慶・延喜・天慶の三度の竟宴の歌を収め、序を伴うものもある。末に契沖の考証と書写奥書がある。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（2ファイル）。 |

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/zoku-gunsho-nihongi-kyoen-waka/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
